Synmact 1.1.13
=================

1. Extract this zip to a folder (for example C:\Synmact). Do not run it from inside the zip.
2. Run Synmact.exe. Windows 10 or 11, 64-bit. Nothing else needs to be installed.
3. First run:
   - "Windows protected your PC": click More info, then Run anyway (the app is not code-signed).
   - The administrator prompt: click Yes. CABAL runs as administrator, and Windows blocks
     clicks from programs with fewer rights.
   - If your antivirus removes the file, allow it (macro tools are sometimes flagged).
4. Open Game setup (top right) and follow the setup guide there.

Keys: F10 start / stop, F11 pause / resume, Ctrl+Alt+F10 hotkeys off / on.
Settings are saved in %APPDATA%\Synmact.

Macro tools can break the game's terms of service. Use at your own risk.
